# MathsEnJeans

**Sujet: Quatre villes**

_On veut construire des routes pour relier entre elles les villes A, B, C et D, en limitant le coût. On veut donc que la longueur totale des routes soit la plus petite possible._

## Questions

1. `Comment faire au mieux dans le cas où les villes sont disposées en carré ?`

2. `Et si elles forment un rectangle ?`

3. `Et si elles sont en 4 points quelconques du plan ?`

4. `Et s’il s’agit de villes du futur, qui flottent dans l’espace ?`

5. `Et pour 3 villes ? 5 villes ? 6 villes ?`

6. `Utiliser GeoGebra pour faire des essais.`

7. `Possibilités de continuation`
